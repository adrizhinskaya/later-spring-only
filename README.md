# Использование сервлетов с Spring Framework и Spring Boot. 
Для работы веб-приложения нужно настроить контейнер сервлетов (Tomcat), контекст приложения WebApplicationContext и сервлет-диспетчер (DispatcherServlet). 
##Ветка servlet_spring содержит способ работы с сервлетами, используя Spring Framework. 
##Ветка servlet_springBoot содержит способ работы с сервлетами, используя Spring Boot.
